# 📊 Student Insomnia and Educational Outcomes - Data Analysis

## 📝 About The Project
This project explores the relationship between average sleep hours, sleep quality, and academic performance among students. Developed as part of the "Introduction to Data Analysis" course, the primary goal was to practice raw data manipulation, Exploratory Data Analysis (EDA), and data visualization to find ways to improve sleep quality and consequently academic achievements.

## 🎯 Key Objectives
* Cleaning and preprocessing the raw dataset.
* Performing Exploratory Data Analysis (EDA) to find hidden trends.
* Visualizing key metrics regarding sleep quality, daily habits (like screen time and physical activity), and their correlation with academic success.

## 🛠️ Built With
* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib / Seaborn**
* **Jupyter Notebook**

## 💡 Main Insights & Findings
* **Insight 1:** People who consume large amounts of caffeine are more likely to feel fatigue during the day. Additionally, caffeine consumption is associated with lower academic performance. These conclusions still hold even among those with good sleep quality.
* **Insight 2:** Physical activity is a very significant factor affecting academic stress. Lack of physical activity significantly increases academic stress.
* **Insight 3:** There is a clear negative correlation between screen time before bed and sleep quality. As screen time increases, sleep quality tends to decrease. On the other hand, there is a clear positive correlation between screen time before sleep and waking up during the night. As screen time increases, waking up during the night tends to increase.
